# 动效设计与实现

## 参考观察

观察对象为 https://www.xdof.ai/ 公开首页。其主要视觉是占据大面积的实时三维 ASCII 场景，配合交互视角、彩色轨迹、逐字出现文字、数据曲线和明暗主题。重点并非长页滚动，而是让一个静态布局内部持续产生变化。

本实现只借鉴这些表现机制，重新创作页面构图、名称、文案、配色与三维几何。没有将参考网站下载的脚本、样式或资源放入此仓库。

## 原创场景

使用 Three.js 的基础圆柱、长方体和二十面体创建机械臂与目标物。模型层级为底座 → 偏航关节 → 肩部 → 肘部 → 腕部 → 夹爪。每个实验以独立的时间函数定义关节转动：

1. Reach & return：肩部、肘部和偏航以错相正弦运动形成往复伸展。
2. Trace a possibility：同步频率与不同相位使末端形成空间循环轨迹。
3. Find a balance：腕部补偿肩部与肘部角度变化，维持夹爪在其平面内的组合角度。

这些是视觉运动实验，不是物理动力学求解或机器人学习实验。

## 字符化

低分辨率离屏 WebGL 渲染 → Canvas 读取颜色与透明度 → 亮度映射到字符集 → 全尺寸 Canvas 绘制。透明像素跳过，减少无意义字符。具有铜色材质的关节部件与目标物保留强调色。

另一个渲染选项将相同采样转为按亮度变化的圆点。字体使用随构建打包的开源字体。

## 运动拖尾与信号

按固定时间间隔保存夹爪末端的世界坐标，在当前相机下重新投影，因此转动视角时轨迹仍处于同一三维空间。最多保留 95 个历史点，每个点画五条逐渐透明的细轨迹。

速度曲线由当前肘关节角度函数的数值导数计算，每次间隔至少 50 毫秒采样，保留最近 8 秒，按实际时间戳定位。画面标记为 simulated，避免将设计动效误认为真实硬件数据。

## 生命周期与可访问性

- 渲染上限约 30 帧/秒，低分辨率三维采样，设备像素比上限为 2。
- 页面隐藏或动画暂停时停止循环，交互和尺寸变化只请求必要帧。
- ResizeObserver 更新场景尺寸；模型通过低分辨率缓冲区绘制。
- 低动态偏好默认暂停，同时立即展示完整文案。
- 视角支持方向键与加减号；弹窗支持 Escape、焦点限制与关闭后焦点恢复。
- 无 WebGL 或上下文丢失时提供程序化 Canvas 2D 备用视图。
- 无需图片、视频或外部模型加载，避免大型素材影响首屏。
