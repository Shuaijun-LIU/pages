# 动效设计与实现

## 参考与构图

参考 https://www.xdof.ai/ 公开首页的四类主体动画：双夹爪持杯、人形采摘、桌前折衣、全身奔跑。本版让场景数量、主视觉比例、淡紫蓝渐变、右侧双信息卡、方块字符、关节轨迹、打字文案和渐隐轮播接近参考。品牌与文案已替换为虚构的 FIELDWORK。

代码独立实现，未发布参考站的脚本、样式或模型。人形采用可再分发的 Unitree G1 模型，双臂与道具为程序化几何。奔跑使用同一 G1，参考中的奔跑主体为人类；动作采用自行编排的关节曲线，没有复用参考动画片段。

## 四个场景

场景定义在 `src/scenes.js`，共享 `{ root, trackers, update(time) }` 接口。

| 场景 | 主体与动作 | 实现 |
| --- | --- | --- |
| Harvest | 完整人形伸手采摘、收回果实 | 肩肘逆运动学、平滑目标插值、物体跟随 |
| Transfer | 两套独立关节臂、夹爪与杯子 | 镜像关节曲线、腕部补偿、杯子随双末端移动 |
| Fold | 人形、桌面与可折叠布面 | 双臂逆运动学、网格折叠与轻微波纹 |
| Run | 全身奔跑、摆臂与身体起伏 | 交替髋膝运动、反相肩肘、骨盆起伏 |

它们是视觉编排，不是接触物理仿真、真实实验轨迹或视频动作提取。

## 模型准备

`public/models/humanoid.glb` 来自 MuJoCo Menagerie 的 Unitree G1，保留 29 个关节和 34 个视觉网格。通过 CPU 顶点聚类降为约 9.7 万个三角形、1.66 MB。坐标转换为 Y 向上、Z 向前，保留关节轴、绑定姿态与名称；移除碰撞及标志几何。

来源、提交、输入校验和与转换参数见 `public/models/humanoid-source.json`，BSD-3-Clause 许可随站点发布。重建方式：

```sh
node scripts/build-robot-asset.mjs /path/to/mujoco_menagerie/unitree_g1
```

模型已包含在仓库，正常构建不需要下载或运行转换脚本。

## 方块字符与粒子

`MotionStudy` 先以低分辨率 WebGL 渲染三维场景，再读取透明度与亮度，以 Canvas 绘制空心方块、带内核方块和实心方块。手绘几何字形保证不同系统一致。POINTS 模式把同一采样转换为亮度控制的圆点。

桌面采样间距约 13 CSS px，窄屏约 8 px。完整模型仍可通过拖动、方向键和缩放查看。明暗主题共用几何与动画，只改变字符、轨迹和背景配色。

## 轨迹、曲线与切换

- 跟踪手腕、肘、膝、踝等多个关节，约每 65 ms 保存世界坐标，每条保留 58 个点。按当前相机重新投影，以细线与散点渐隐显示。
- 四条曲线取当前运动的关节角度、数值角速度、数值角加速度与场景运动信号。分别归一化显示最近 8 秒；标为 `SIMULATED`，不充当硬件测量。
- 自动轮播约每 8 秒换场景，先 0.7 秒字符消散，再 0.9 秒聚合。每个栅格用稳定散列决定出现顺序。
- 可手动选择四个场景、关闭自动轮播、独立暂停。暂停状态切换场景立即呈现完整模型。
- 切换时清理旧轨迹、曲线与数值导数历史，并更新按钮、无障碍文字与标题。

## 生命周期与可访问性

渲染上限约 30 fps，设备像素比上限 2。页面隐藏或暂停时停止动画循环，交互与尺寸变化请求必要帧。低动态偏好默认暂停并关闭轮播，文字完整显示。主题持久保存；弹窗支持 Escape 和焦点恢复。

WebGL 不可用、上下文暂时丢失或模型加载失败时，提供可切换的二维字符主体备用视图。上下文恢复时重建正确的渲染尺寸。字体与模型均随网站部署，无需运行时外部模型服务。
